# Brumbar character helper

Мобильный лист персонажа для Брумбара «Бочкобрюха». Приложение показывает формулы, модификаторы и активные правила, но не бросает кубы.

## Локальный запуск

```bash
cd apps/brumbar
pnpm install
pnpm dev
```

## Данные

Приложение загружает `apps/brumbar/public/character.json`, а затем автоматически сохраняет изменения в браузере. В разделе «Инвентарь» можно импортировать или скачать совместимый JSON.

Статический GitHub Pages не может самостоятельно изменять файлы репозитория. В Chromium-браузерах доступна дополнительная кнопка «Связать файл»: выбранный локальный JSON обновляется после каждого изменения, пока страница открыта.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает и публикует приложение при каждом push в `main`. В настройках репозитория выберите **Settings → Pages → Source → GitHub Actions**.
